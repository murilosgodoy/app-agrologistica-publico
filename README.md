# Agrologística — Central de Recados

Instaladores do app da central de agrologística.

## Baixar

Vá em **[Releases](../../releases/latest)** e baixe:

- **Windows:** `Agrologistica-X.Y.Z-windows-setup.exe` → execute e siga o instalador.
- **Android:** `Agrologistica-X.Y.Z-android.apk` → abra no celular e instale. Na primeira vez, o Android pede para permitir "instalar apps desconhecidos" para o navegador ou gerenciador de arquivos.

O app avisa sozinho quando há versão nova.

> Uso interno. É preciso ter usuário cadastrado para entrar.
